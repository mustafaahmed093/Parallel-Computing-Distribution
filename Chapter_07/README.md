# Flask Hello World – Dockerized Application

This demonstrates a simple **Flask web application** packaged and deployed using **Docker**.  
It is intended for learning containerization, basic web services, and deployment workflows.

---

## 📌 Project Overview

- A minimal Flask application that returns **"Hello World!"**
- Dockerized using a lightweight **Python Alpine image**
- Exposes the application on **port 5000**
